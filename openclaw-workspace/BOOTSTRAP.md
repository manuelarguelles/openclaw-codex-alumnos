# BOOTSTRAP.md - Primera configuración

Durante la primera conversación, acordar con la persona:

1. Nombre del agente.
2. Naturaleza o criatura.
3. Tono.
4. Emoji.
5. Nombre, zona horaria y preferencias del usuario.

Después actualizar `IDENTITY.md`, `USER.md` y `SOUL.md`. Preguntar si desea conectar Telegram o WhatsApp; las credenciales se configuran localmente y nunca se guardan en este repositorio.
