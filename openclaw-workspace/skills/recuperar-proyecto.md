# recuperar-proyecto

Recupera el contexto de un proyecto archivado (personal o Apex) desde el índice maestro, para retomar el trabajo. Usar cuando el usuario diga "recuperar proyecto <nombre>", "retomar <proyecto>", "traé el contexto de <proyecto>", "/recuperar-proyecto <nombre/contexto>", o pregunte en qué quedó un proyecto.
