01

Tu identidad

Crea tu cuenta de GitHub

GitHub será el lugar donde guardaremos una copia privada de tu proyecto.

  1. Abre github.com/signup.
  2. Registra un correo al que tengas acceso y confirma el mensaje.
  3. Elige un nombre de usuario fácil de recordar. No compartas tu contraseña.
  4. Recuerda que tus repositorios de clase deben ser privados.
Listo: puedes entrar a GitHub y sabes cuál es tu nombre de usuario.

03

La puerta segura

Conecta GitHub desde el navegador

Autorizas a GitHub sin copiar una contraseña ni un token en Telegram.

Cuando OpenClaw indique que falta autenticación, inicia el flujo web:

Equivalente que ejecuta OpenClaw
gh auth login --web --git-protocol https
  1. Elige GitHub.com.
  2. Elige HTTPS.
  3. Elige Login with a web browser.
  4. Usa el código temporal únicamente en la página oficial de GitHub.
  5. Vuelve al chat y pide comprobar la conexión.
Nunca escribas en el chat: tu contraseña, un token, una API key ni el resultado de gh auth token.
04

La conversación

Pídeselo a OpenClaw en lenguaje simple

OpenClaw traduce tu intención a comandos y te devuelve pruebas.

«Comprueba si Git y GitHub CLI están instalados y si mi cuenta está conectada. Ejecuta git --version, gh --version y gh auth status. No muestres tokens. Dime qué falta y detente».
«Trabaja solo dentro de [RUTA]/mi-primer-proyecto. Dime qué cambió, prepara únicamente README.md y RECOVERY-DEMO.md, enséñame la revisión y espera mi aprobación antes de hacer commit o push».

¿Qué cambió?

OpenClaw usa git status.

¿Qué publico?

OpenClaw usa git push, solo tras tu aprobación.

¿Qué recupero?

OpenClaw usa git restore para un archivo de prueba.

¿Puedo reconstruirlo?

OpenClaw usa gh repo clone en otra carpeta.

Comprobación final

Tu conexión está lista cuando puedes demostrar esto

  • gh auth status confirma tu cuenta sin mostrar secretos.
  • OpenClaw trabaja dentro de la carpeta correcta.
  • El repositorio será privado y publicarás solo después de revisar.
  • Puedes obtener URL, rama, hash y estado limpio tras el push.
