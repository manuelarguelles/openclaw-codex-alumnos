Agentes AI con OpenClaw + Codex

Sesión 1 · Guía de instalación

Tu primer agente, en cuatro pasos

Al terminar esta guía tendrás OpenClaw instalado, Codex conectado y un agente que recibe tareas desde Telegram. No necesitas empezar escribiendo código.

Telegram→gateway→Codex→herramienta
1 · Instalar 2 · Onboarding 3 · Telegram 4 · Identidad Comprobación final

Antes de comenzar

Selecciona tu sistema operativo

01

El cuerpo

Instala OpenClaw por el camino soportado

El instalador prepara el programa y sus dependencias. Después comprobaremos la versión.

Abre PowerShell —tecla Windows y escribe “PowerShell”— y pega esta línea:

PowerShell · Windows
iwr -useb https://openclaw.ai/install.ps1 | iex
Durante esta sesión no usamos Windows Hub ni WSL. El carril de PowerShell instala el gateway nativo de Windows y evita permisos de administrador y reinicios innecesarios.

Abre Terminal —Cmd + Espacio y escribe “Terminal”— y pega esta línea:

Terminal · macOS y Linux
curl -fsSL https://openclaw.ai/install.sh | bash
Si el comando todavía no aparece: cierra Terminal, vuelve a abrirla e inténtalo otra vez. Una instalación nueva puede requerir una sesión de terminal nueva.
Comprobar la instalación
openclaw --version
Paso 1 terminado: el comando devuelve un número de versión.
02

El cerebro y el servicio

Conecta Codex y deja el gateway funcionando

El onboarding convierte tus decisiones en configuración persistente.

Iniciar el onboarding
openclaw onboard --install-daemon

Motor de la sesión

Selecciona Codex e inicia sesión con tu cuenta de ChatGPT cuando se abra el navegador.

Servicio permanente

Daemon describe el régimen de ejecución: el gateway permanece disponible en segundo plano aunque cierres la terminal.

Comprobar el gateway
openclaw gateway status
Paso 2 terminado: el estado muestra el servicio activo y Codex completa una respuesta real.
Si algo no coincide: ejecuta openclaw status y después openclaw doctor --fix. Corrige una sola capa antes de volver a probar.
03

El canal

Conecta Telegram y autoriza tu conversación

El token identifica al bot; el pairing decide quién puede hablar con él.

1. Crea un bot nuevo

En Telegram, abre @BotFather, envía /newbot y define un nombre visible y un usuario único. BotFather te entregará un token.

El token es una credencial. No lo compartas en el chat, no lo incluyas en capturas y nunca lo subas al repositorio. Si se filtra, revócalo en BotFather.

2. Configura el canal

Abre la configuración, selecciona Telegram y pega el token solamente cuando OpenClaw lo solicite.

Configurar Telegram
openclaw configure

3. Completa el pairing

Envía hola al bot desde tu teléfono. Si devuelve “access not configured” y un código, el canal está protegiéndote correctamente. Autoriza ese código desde tu máquina:

Reemplaza TUCODIGO
openclaw pairing approve telegram TUCODIGO
Paso 3 terminado: envía hola otra vez. El agente debe responder a tu cuenta autorizada.
04

La identidad y la prueba

Define el carácter por chat y comprueba un efecto real

La identidad se solicita con lenguaje natural; la validación exige evidencia fuera del chat.

Cuando el agente te pregunte quién debe ser, responde desde Telegram con tus propias palabras. Por ejemplo:

Te llamas Nina y tu emoji es 🦊. Respondes de forma breve y directa, en español. Si no sabes algo, lo indicas en lugar de inventarlo. Trátame siempre de tú.
Lo que ocurre detrás: OpenClaw convierte esa conversación en archivos revisables del workspace. En la Sesión 2 trabajaremos con IDENTITY.md, SOUL.md, AGENTS.md y TOOLS.md.

Finalmente, envía esta tarea desde Telegram:

Lee el README del workspace. Crea agente-ok.md con mi nombre, la fecha, tres cosas que entendiste del proyecto y una tarea que me gustaría automatizar. Dime la ruta exacta.
Paso 4 terminado: el archivo existe en el workspace, su contenido coincide con la solicitud y Telegram devuelve la ruta correcta.

Criterio de aceptación de la S01

El agente funciona cuando puedes demostrar el recorrido completo

  • El mensaje sale de tu cuenta autorizada de Telegram.
  • El gateway permanece activo aunque cierres la terminal.
  • Codex interpreta la tarea y OpenClaw utiliza una herramienta.
  • agente-ok.md existe y la respuesta informa su ruta.
  • Ningún token, secreto o credencial entra al repositorio.
