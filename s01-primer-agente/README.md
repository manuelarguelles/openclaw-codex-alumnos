# S01 · Tu primer agente

## Objetivo

Demostrar el recorrido completo:

`Telegram → gateway → Codex → herramienta → archivo → respuesta`

## Reto

Envía por Telegram:

> Lee el README del workspace. Crea `agente-ok.md` con mi nombre, la fecha, tres cosas que entendiste del proyecto y una tarea que me gustaría automatizar. Dime la ruta exacta.

## Evidencia

Crea `entregas/<tu-usuario>/S01.md` con:

- sistema operativo;
- versión de OpenClaw;
- estado del gateway sin tokens;
- texto de la tarea;
- ruta y contenido de `agente-ok.md`;
- explicación breve de qué hicieron Telegram, el gateway, Codex y la herramienta.

## Aprobación

- [ ] La cuenta de Telegram está emparejada.
- [ ] El gateway inicia después de reiniciar.
- [ ] El archivo existe en el workspace.
- [ ] La respuesta de Telegram informa la ruta correcta.
- [ ] No hay secretos en el commit.
