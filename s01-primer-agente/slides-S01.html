Construcción en vivo13 / 46

Instalación

El instalador pone el cuerpo; el onboarding decide cómo se comporta

# macOS / Linux curl -fsSL https://openclaw.ai/install.sh | bash
# Windows PowerShell · gateway nativo, sin WSL iwr -useb https://openclaw.ai/install.ps1 | iex

Después

openclaw onboard --install-daemon

Verificación

openclaw gateway status debe mostrar el servicio activo.

Canal vs. identidad23 / 46

Pairing
