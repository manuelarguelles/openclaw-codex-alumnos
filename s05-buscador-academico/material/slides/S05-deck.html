SDD aplicado

La spec define qué aceptar incluso cuando una fuente falla

Entrada: tema, periodo y límite.
Salida: registros únicos, procedencia y errores por fuente.

CA = criterio de aceptación. La mini-spec es un borrador para revisión, no una implementación.

S05 · Adelanto v0.19 / 24

Teoría con ejemplo

Una API permite pedir datos con un contrato de entrada y respuesta

Petición: consulta «AI tutoring», hasta cinco registros.
Respuesta: campos como título, autores, año e identificador.
El adaptador transforma cada respuesta al formato común.

API = interfaz entre programas. Adaptador = traductor de un formato a otro.

S05 · Adelanto v0.110 / 24

Fuentes 1/3

Crossref aporta metadatos y arXiv aporta registros de preprints

Crossref: títulos, autores y DOI depositados por sus miembros.
arXiv: búsqueda en registros de trabajos, incluidos preprints.
Un registro encontrado todavía necesita revisión de pertinencia.

DOI = identificador persistente. Preprint = versión difundida antes de la revisión editorial formal.

www.crossref.org/documentation/retrieve-metadata/rest-api/ · info.arxiv.org/help/api/basics.html

S05 · Adelanto v0.112 / 24
★

Fuentes 3/3

CORE busca literatura y Unpaywall enriquece un DOI ya encontrado

CORE: acceso a registros de literatura de repositorios.
Unpaywall: localización de acceso abierto a partir de un DOI.
Primero descubrimos trabajos, después buscamos su acceso abierto.

Unpaywall no ocupa una rama de búsqueda textual genérica.

core.ac.uk/documentation/api · unpaywall.org/products/api

S05 · Adelanto v0.116 / 24

Ejercicio de deduplicación

Un duplicado se consolida conservando su procedencia

Dos respuestas con el mismo identificador representan un candidato único.
Conservamos ambas fuentes.
Sin identificador, título y año solo proponen una coincidencia para revisar.

La práctica incluye tres registros sintéticos. No fusionar trabajos solo porque sus títulos se parecen.

S05 · Adelanto v0.117 / 24

Relevancia

El ranking debe explicar por qué un resultado aparece primero

Ejemplo didáctico: primero cumple tema y periodo, después desempata por fecha.
Un conteo alto de citas no prueba pertinencia ni calidad.
El alumno debe poder justificar la posición de cada resultado.

Ranking = orden por criterios. La regla del ejercicio no es un estándar bibliométrico.

S05 · Adelanto v0.118 / 24

Introducción conceptual

Los embeddings aproximan significado y RAG usa evidencia recuperada

Búsqueda exacta: coincide una palabra.
Embedding: representación numérica que aproxima semejanza de significado.
RAG: recuperar información y usarla como contexto para responder.

«Tutoría inteligente» puede relacionarse con «AI tutoring». No toda búsqueda usa embeddings ni toda API implementa RAG.

S05 · Adelanto v0.119 / 24

Salida académica

Una cita verificable conserva campos reales y declara lo que falta

Autor, fecha, título, publicación e identificador según disponibilidad.
El JSON conserva campos y procedencia.
La referencia legible permite revisar el registro original.

Formato APA requiere revisar tipo de documento y metadatos. No inventamos autor, año, DOI ni conclusiones.

S05 · Adelanto v0.120 / 24

Errores y recuperación

Un fallo visible permite recuperarse sin fingir una búsqueda completa

429: límite de peticiones. Esperar según el proveedor.
Timeout: se agotó la espera. Reportar fuente y límite.
Sin credencial: omitir esa fuente explícitamente.
La práctica sin red usa datos sintéticos.

Fixture = dato de prueba controlado. La fixture no acredita conectividad real.

Checkpoint de calidad
