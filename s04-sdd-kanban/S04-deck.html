S04 · Ciclo SDD completo32 / 46

Caso · RED

El starter falla porque aún no reconoce un cierre válido

node --test tests/cierre.test.mjs

Esperado Hecho; obtenido Revisión.

12 tests: 11 PASS y 1 FAIL. El fallo positivo impide una función que siempre rechace.

S04 · Ciclo SDD completo33 / 46

Caso · GREEN

La implementación mínima exige evidencia por cada criterio

01

Criterios únicos y no vacíos; una evidencia PASS por ID.

02

Referencia no vacía, revisión APROBADA y autorización === true.

03

La solución docente obtiene 12 PASS; el alumno construye la suya.

Caso · debugging

Una lista vacía revela un error que parece correcto

01

Hipótesis: every() devuelve true para [].

02

Reproducir antes de corregir; localizar la guarda ausente.

03

Exigir al menos un criterio y repetir el caso y toda la suite.

S04 · Ciclo SDD completo35 / 46

Caso · REFACTOR

Una regresión comprueba que el arreglo no rompió lo que funcionaba

01

Conservar los 12 casos mientras simplificas la función.

02

Probar false frente a "false", evidencia duplicada y datos inválidos.

03

La evidencia debe corresponder al código que se entregará.

S04 · Ciclo SDD completo37 / 46

Checkpoint 3 · runtime

La conducta del agente se ensaya con casos distintos

  • Tarea permitida: ejecutar y mostrar evidencia.
  • Prueba fallida: reportar parcial, conservar Revisión.
  • Criterio ambiguo o cierre no autorizado: preguntar o esperar.
  • Registrar respuestas reales; una salida ilustrativa no es una prueba.
